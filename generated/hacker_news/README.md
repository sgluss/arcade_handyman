## Tools

| Tool | Returns |
|---|---|
| `get_item` | Item object with fields like by, descendants, id, kids, score, time, title, type, url, text, parent, poll, parts, deleted, dead. |
| `get_user` | User object with about, created, id, karma, and submitted (list of item ids). |
| `list_top_stories` | List of story item ids, ranked by current top placement. |
| `list_new_stories` | List of story item ids, newest first. |
| `list_best_stories` | List of story item ids, best-ranked first. |
| `list_ask_hn_stories` | List of Ask HN story item ids, most recent first. |
| `list_show_hn_stories` | List of Show HN story item ids, most recent first. |
| `list_job_stories` | List of job story item ids, most recent first. |

## Endpoints deliberately not exposed

- `get_max_item_id`: internal bookkeeping value for crawling all items, not useful to an agent answering user questions
- `get_updates`: low-level change-feed for sync/crawling infrastructure, not a meaningful agent-facing query
