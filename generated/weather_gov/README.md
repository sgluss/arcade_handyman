# Weather.gov (NWS)

Generated by [Handyman](../../README.md) from `https://api.weather.gov/openapi.json`. Do not edit by hand —
regenerate instead. The full design decision, including everything below, is in
[plan.json](plan.json).

Run locally:

```bash
uv run generated/weather_gov/server.py stdio   # or: http
```

## Tools

| Tool | Returns |
|---|---|
| `get_active_alerts` | List of active alert features with properties (headline, severity, urgency, certainty, areaDesc, effective, expires, description, instruction). |
| `get_alert_details` | Full alert object including area description, affected zones, sent/effective/onset/expires times, and instructions. |
| `get_forecast` | List of forecast periods, each with name, temperature, wind, and a short forecast description. |
| `get_hourly_forecast` | List of hourly forecast periods, each with start time, temperature, wind, and short forecast description. |
| `get_current_conditions` | Latest observation for the nearest station: temperature, wind speed/direction, humidity, visibility, textDescription, and timestamp. |

## Configuration

| Env var | Required | Purpose |
|---|---|---|
| `WEATHER_GOV_USER_AGENT` | optional (default: `weather-gov-mcp-server (contact@example.com)`) | Identifies this application to the weather.gov API, as required by their usage policy. |

## Endpoints deliberately not exposed

- `alerts_query`: historical/broad alert search is redundant with get_active_alerts for realistic agent queries
- `alerts_active_count`: aggregate count rarely useful to agents; get_active_alerts covers the need
- `alerts_active_zone`: redundant with point/area filtering already exposed in get_active_alerts
- `alerts_active_area`: covered by area argument in get_active_alerts
- `alerts_active_region`: marine-region alerts too niche for general agent use
- `alerts_types`: administrative reference list, not a user-facing query
- `gridpoint`: raw numerical grid data is too low-level; textual forecast endpoints serve agents better
- `gridpoint_stations`: internal plumbing, superseded by point_stations chain in get_current_conditions
- `point`: internal lookup only, hidden inside forecast/current-conditions tools
- `point_stations`: internal lookup only, hidden inside get_current_conditions
- `point_radio`: niche radio broadcast script, not a typical agent request
- `obs_stations`: station directory browsing is plumbing, not an agent-facing need
- `obs_station`: station metadata lookup, too niche standalone
- `station_observation_list`: historical observation history is niche; latest observation covers common need
- `station_observation_time`: requires exact timestamp lookup, too niche for agents
- `tafs`: aviation-specific terminal forecast, niche audience
- `taf`: aviation-specific single TAF lookup, niche audience
- `sigmetQuery`: aviation SIGMET data too specialized for general agent use
- `sigmetsByATSU`: aviation-specific, niche
- `sigmetsByATSUByDate`: aviation-specific, niche
- `sigmet`: aviation-specific, niche
- `cwsu`: aviation center metadata, administrative
- `cwas`: aviation advisories, niche
- `cwa`: aviation advisories, niche
- `glossary`: reference data, not a weather query
- `icons`: deprecated icon rendering endpoint
- `iconsDualCondition`: deprecated icon rendering endpoint
- `icons_summary`: deprecated icon reference list
- `satellite_thumbnails`: deprecated image service
- `office`: administrative office metadata, not weather content
- `office_briefing`: internal office briefing, niche
- `office_briefing_download_latest`: internal office briefing, niche
- `office_briefing_download`: internal office briefing, niche
- `office_headline`: office news headline, niche
- `office_headlines`: office news headlines, niche
- `office_weatherstory`: niche office-specific content
- `office_weatherstory_image`: niche image asset
- `radar_servers`: administrative radar infrastructure metadata
- `radar_server`: administrative radar infrastructure metadata
- `radar_spgds`: administrative radar infrastructure metadata
- `radar_stations`: radar station directory, niche for agents
- `radar_station`: radar station metadata, niche
- `radar_station_alarms`: administrative radar alarms
- `radar_queue`: administrative radar product queue
- `radar_profiler`: specialized wind profiler data, niche
- `transmitters`: NOAA radio transmitter directory, niche
- `transmitter`: NOAA radio transmitter metadata, niche

- `products_query`: raw text product search too low-level for general agent queries
