## Tools

| Tool | Returns |
|---|---|
| `get_item` | Object with fields such as id, type, by, time, text, url, title, score, descendants, kids (comment ids), parts (poll option ids), parent, deleted, dead. |
| `get_user` | Object with id (username), created (unix timestamp), karma, about (bio HTML), and submitted (list of item ids). |
| `get_top_stories` | Array of up to 500 item ids, ranked from top to bottom. |
| `get_new_stories` | Array of up to 500 item ids, newest first. |
| `get_best_stories` | Array of item ids ranked by score. |
| `get_ask_stories` | Array of up to 200 Ask HN item ids, most recent first. |
| `get_show_stories` | Array of up to 200 Show HN item ids, most recent first. |
| `get_job_stories` | Array of up to 200 job item ids, most recent first. |

## Endpoints deliberately not exposed

- `get_max_item_id`: administrative/crawler primitive, not a query an agent asks
- `get_updates`: niche polling feed for building sync systems, not a typical content request
