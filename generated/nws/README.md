# National Weather Service

Generated by [Handyman](../../README.md) from `https://api.weather.gov/openapi.json`. Do not edit by hand —
regenerate instead. The full design decision, including everything below, is in
[plan.json](plan.json).

Run locally:

```bash
uv run generated/nws/server.py stdio   # or: http
```

## Tools

| Tool | Returns |
|---|---|
| `get_forecast` | List of forecast periods (name, temperature, wind, short/detailed forecast text) for the given point. |
| `get_hourly_forecast` | List of hourly forecast periods (start/end time, temperature, wind, short forecast text) for the given point. |
| `get_current_observations` | Latest observation for the nearest station: timestamp, temperature, wind, humidity, pressure, and textual description. |
| `get_active_alerts` | List of active alert features, each with properties like event, severity, headline, description, and affected area. |
| `get_alert_details` | Full alert record including area description, affected zones, timing, status, and message type. |
| `get_text_product` | Text product record with issuing office, issuance time, product code/name, and full product text. |
| `get_latest_text_product` | The latest text product for the given type and location, including full product text. |

## Configuration

| Env var | Required | Purpose |
|---|---|---|
| `NWS_USER_AGENT` | optional (default: `weather-mcp-server (contact@example.com)`) | Identifies the application to the NWS API; should include an app name and contact email. |
| `NWS_API_KEY` | optional (default: `None`) | Optional API key for endpoints testing the newer key-based access system. |
